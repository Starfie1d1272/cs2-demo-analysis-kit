# CS2 HUD SVG assets

These SVG files are the common CS2 HUD/death-notice assets used by
CS2 Insight Agent. They are included in DAK Studio with the author's
explicit permission and are reused only as presentation assets.

Source integration:

- CS2 Insight Agent: `frontend/public/hud-death-notice/`
- Original asset naming follows the HLAE / One Studio CS:GO HUD generator set.
