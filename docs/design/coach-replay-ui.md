# 教练工作台与统一回放 UI 设计

## 目标

教练工作台的“开局模式”改为回放优先：模式列表负责选择样本，2D 回放常驻主画布，战术摘要与证据回合围绕同一回放联动。删除固定三/四切片 UI 和对应 facts；比赛工作台与教练工作台只使用 `@cs2dak/react` 的同一个 `ReplayViewer`、同一个比赛时钟和同一个回合边界合同。

## 页面结构

开局模式页保持三栏，但重新分配主次：

1. 左栏：T/CT 切换、开局粗分类、具体模式、样本数与胜率。
2. 中栏：常驻 `ReplayViewer`，占据主要宽度。切换模式后自动选择代表回合；点击证据回合只切换该画布的数据。
3. 右栏：模式解释、统计、经济分布和证据回合列表。证据行不再提供“打开页内回放”，整行选择即更新主画布；仍保留跳转比赛工作台。

不再存在“站位视图 ↔ 页内回放”的条件切换、返回按钮或第二套回放生命周期。回放模型缓存由 `PatternExplorer` 的稳定 `useRef` 持有，且按 matchId 直接读取，不扫描全部比赛 workspace facts。

## 回放初始位置

- 比赛工作台：进入回合默认定位到 freeze end，即比赛钟 `1:55`。
- 教练工作台：默认定位到 freeze end 后 20 秒，即比赛钟 `1:35`。
- 用户点击带 tick 的证据入口时，显式 tick 优先于默认位置。
- 切换回合后停止播放并按调用方默认位置定位，不回到 replay 原始 frame 0。

## 统一比赛时钟

`WorkspaceReplayRound` 增加 `freezeEndTick`。`ReplayViewer` 使用共享纯函数计算四阶段时钟：

1. `freeze`：freeze end 前显示“准备”；
2. `round`：freeze end 后从 `1:55` 向下倒计时；
3. `bomb`：C4 安放后从实际可推导的爆炸时长倒计时；有爆炸事件时使用 `explodeTick - plantTick`，否则回退 40 秒；
4. `round-end`：官方回合结束后，根据 `targetEndTick`（下一回合 start tick）显示真实赛后间隔倒计时。

比赛钟是主状态；raw tick、帧数和采样率降级到次级技术信息。所有“执行剩余”“下包时间”统一显示 `M:SS`，禁止显示 `88s` 这类裸秒。

## 战术 facts 精简

`TacticalRoundFact` 删除 `snapshots[]`。固定 1:35/1:10/0:55 等切片不再参与聚类或展示；开局模式只使用 `openingPattern` 的连续驻留证据和 coarse/detailed signature。

`TACTICAL_FACT_VERSION` 升级。旧 facts 继续通过现有“需要重建”路径淘汰。

## 前压与默认位语义

开局代表位置按以下优先级选择：

1. 在 30 秒开局窗口中连续驻留达到阈值的已确认默认位；
2. 已知 A/B/Mid 倾向中连续驻留最长的位置；
3. 无法分类的位置保持 unknown。

展示名称必须来自默认位锚点或 callout 中文名，不显示引擎英文 ID。快速前压到对方出生区域（例如 CT eco 局冲到 Outside/匪口）应显示实际 callout 与“前压”状态，不得冒充本方默认位。前压由“非本方默认位 + 已知方向/对方默认位 + 到达时间”动态推导，不能恢复静态 `advanced` 表。

## 说明与可访问性

- 教练页所有派生指标统一使用共享 `MetricInfo`，不再使用仅依赖 `title` 的私有 ⓘ。
- 每个说明必须包含口径、时间锚点和主要限制；无内容时不渲染图标。
- `ReplayViewer` 的按钮、时钟和证据行保留明确的 aria label、选中态和键盘可操作性。

## 完成标准

- 教练开局页首屏始终是模式列表 + 常驻回放 + 摘要/证据，不再显示切片雷达。
- `TacticalRoundFact` 和 Studio 代码无 `snapshots` 战术切片依赖。
- 教练回放默认 `1:35`；比赛工作台默认 `1:55`。
- 两处使用同一个 `ReplayViewer` 与共享时钟函数。
- C4、回合内和赛后阶段均显示倒计时。
- 执行/下包时间全部采用 `M:SS`。
- 前压位置不被错误归为默认位，且 UI 显示中文 callout/“前压”。
- 教练页无私有空说明图标。
- 直接加载单场 workspace，不调用 `getAll()` 扫描全部回放。
- 相关组件测试、facts 测试、全仓 typecheck、全仓 Vitest 和 build 通过。
